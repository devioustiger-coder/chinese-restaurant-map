# West Coast Chinese Restaurant & Asian Population Map

An interactive city-level research map comparing Chinese restaurant availability with Asian and Chinese population patterns across 30 cities in Washington, California, and Oregon.

The project includes a Bellevue census-tract detail view alongside the primary city-level comparison. Population estimates come from the 2024 ACS 5-year release. Restaurant locations are OpenStreetMap lower-bound estimates and cuisine classifications do not identify ownership.

## Live map

Published with GitHub Pages.

## Files

- `index.html` — interactive Leaflet map
- `data/cities.geojson` — city boundaries and summary statistics
- `data/asian_restaurants.geojson` — classified restaurant points
- `data/businesses.geojson` — original Bellevue business sample
- `data/tracts.geojson` — Bellevue census-tract context
